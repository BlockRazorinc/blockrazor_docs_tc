# Fast Submit

### 產品介紹

Fast Submit 是 BSC Block Builder 的專屬交易提交通道，用於提升交易提交的速度與穩定性。

對於時延敏感型交易來說，交易是否能夠更快、更穩定地到達Block Builder，往往會直接影響提交效果。額外的代理層、跨區域網絡抖動，以及請求處理鏈路中的額外開銷，仍然可能帶來不必要的交易延遲。

相比通用的公共提交通道，Fast Submit 重點優化客戶端到 Builder 之間的網絡路徑與請求處理路徑。它的核心目標很明確：

* 讓交易更快到達 Builder
* 讓提交鏈路在高負載和跨區域場景下更穩定
* 減少由額外代理、網絡波動和重復處理帶來的可避免開銷

### 為什麼 Fast Submit 更快、更穩

**1. 專屬 HTTP 域名**

Fast Submit 提供專屬 HTTP 域名用於交易提交。通過將 CloudFront 代理層改為 DNS 直接解析，減少中間轉發環節和 TLS 認證帶來的額外網絡開銷。這意味著請求路徑更直接，網絡跳數更少，額外時延和波動都會更低。

**2. 跨洲專線**

Fast Submit 使用跨洲專線網絡提交交易至Block Builder，減少公網路由波動、擁塞和抖動這類不穩定因素對交易請求的影響。

### 價格

Fast Submit僅包含於極速服務包中，請前往[訂閱](https://blockrazor.io/#/pricing)頁面採購極速服務包，訂閱完成後請[聯繫](https://discord.gg/qqJuwRb8Nh)我們接入專屬域名

### 接入方式

開發者只需將現有的 HTTP 提交請求，切換到專屬的 Fast Submit 域名即可。接入流程如下：

1. 前往[訂閱](https://blockrazor.io/#/pricing)頁面採購極速服務包
2. [聯繫](https://discord.gg/qqJuwRb8Nh)我們，獲取 Fast Submit 專屬接入域名
3. 保持原有請求邏輯不變，將現有交易提交請求發送到該專屬 HTTP 域名
4. 從實際部署區域測試提交時延與穩定性表現，與原有提交通道進行對比評估

### 注意事項

Fast Submit 旨在優化交易到達 BSC Block Builder 的速度與穩定性，但不保證交易一定會被打包。Fast Submit 是一項面向提交鏈路的基礎設施優化能力，而不是打包結果承諾。

最終是否被納入區塊，仍然取決於多種提交鏈路之外的因素，包括但不限於：市場競爭情況、Builder 處理策略、當前區塊空間、交易質量和鏈上實時擁堵狀態等。
